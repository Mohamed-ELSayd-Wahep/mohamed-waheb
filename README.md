# موقع ومعرض الأعمال الشخصي للمطور محمد وهيب
## Mohamed Waheb - Frontend & UI/UX Developer Portfolio

موقع شخصي ومعرض أعمال متكامل، فائق السرعة، ومطور باحترافية عالية لـ **محمد وهيب (Mohamed Waheb)**، مطور واجهات أمامية ومصمم تجارب مستخدم حُر (Freelance Web Developer & UI/UX Designer)، باللغة العربية الفصحى مع دعم شامل ودقيق لاتجاه اليمين إلى اليسار (RTL).

---

## 🌟 محتويات المشروع وأقسامه

1. **الصفحة الرئيسية لمعرض الأعمال (`index.html`):**
   - **الهيدر والتنقل:** شريط علوي زجاجي تفاعلي (Glassmorphism)، زر تبديل الوضع (Dark/Light)، وروابط التمرير الذكي (ScrollSpy).
   - **القسم الترحيبي (Hero Section):** شارة التوفر للعمل الحر، كود تعريفي منمق للمطور محمد وهيب، إحصائيات رقمية متحركة (+5 سنوات، +45 مشروع، 100% التزام، 99% رضا).
   - **من أنا (About Me):** السيرة المهنية لـ **محمد وهيب** وركائز العمل (السرعة، التجاوب، الكود النظيف، الدعم الفني).
   - **الخدمات (Services):** 4 بطاقات تفاعلية (مواقع الشركات، المتاجر الإلكترونية، حاسبات وأدوات الويب التفاعلية، تسريع وصيانة المواقع).
   - **معرض المشاريع (Portfolio Grid & Filtering):** تصفية حسب التصنيف، نافذة منبثقة غنية (Modal) للتفاصيل، وروابط المعاينة الحية.
   - **مشروع حي مدمج:** يتضمن المعرض مشروعاً حقيقياً متكاملاً لعيادة طب أسنان (`dental-clinic.html`) مع نظام حجز تفاعلي ومقارنة صور قبل وبعد!
   - **المهارات والتقنيات (Skills):** أشرطة تقدم تفاعلية وشارات للتقنيات: HTML5, CSS3, Tailwind CSS, JavaScript ES6+, React, WordPress, Elementor, Figma, Git.
   - **منهجية العمل وآراء العملاء (Process & Testimonials):** 4 خطوات للعمل وشهادات عملاء موثقة.
   - **التواصل المباشر (Contact Form & Direct Channels):** نموذج تواصل مع تحقق فوري (Validation)، إشعار نجاح (Toast)، ورابط واتساب مباشر.

2. **مشروع العيادة الطبية المكتمل (`dental-clinic.html`):**
   - صفحة هبوط لعيادة طبية متطورة ("ابتسامة النيل لطب الأسنان") كمثال عملي قوي ضمن معرض أعمال محمد وهيب.
   - يتضمن عارض مقارنة قبل وبعد تفاعلي، نظام فلترة للخدمات، ونظام حجز إلكتروني مع إيصال رقمي مؤكد وتأكيد واتساب.

## 📁 هيكل الملفات المنظم

```text
├── index.html            # صفحة معرض الأعمال الشخصي للمطور محمد وهيب
├── dental-clinic.html    # مشروع العيادة الطبية التفاعلي المتكامل (Showcase Project)
├── css/
│   ├── style.css         # التنسيقات المخصصة والمؤثرات لمعرض الأعمال (Glassmorphism, Animations)
│   └── clinic.css        # التنسيقات الخاصة بمشروع العيادة الطبية
├── js/
│   ├── main.js           # المنطق التفاعلي لمعرض الأعمال (فلترة، مودال، عدادات، تحقق)
│   └── clinic.js         # المنطق البرمجي الخاص بنظام حجز العيادة وسلايدر المقارنة
└── README.md             # دليل التوثيق والتشغيل
```

## 🚀 التشغيل المباشر والمعاينة

1. افتح ملف `index.html` في متصفح الويب المفضل لديك.
2. أو شغل خادم ويب محلي:
   ```bash
   python -m http.server 8000
   ```
   ثم توجه إلى: `http://localhost:8000`
